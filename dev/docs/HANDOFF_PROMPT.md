# Starting a new Claude session

`CLAUDE.md` is loaded automatically in every session, so a short opener is enough:

> Follow CLAUDE.md strictly. My request: …

## Request template (copy, fill in, delete the lines you don't need)

```
Follow CLAUDE.md strictly.

TYPE: mechanic / art / VFX / UI / story & dialogue / bug / voices / question only
WHERE: the boss, phase, scene or screen (e.g. "Big Back Hamza, phase 2", "Omar's scythe combo", "Esc menu")

WHAT I WANT:
1. …
2. …

FOR BUGS: what I did → what happened → what I expected (and how often it happens)

KEEP AS IS: what must not change (hitboxes, timings, other bosses, the look of …)
FREEDOM: "exactly this" or "creative control"
VOICE NEW LINES: no (default) / yes
```

Tips
- One idea per numbered line; a long list is fine, numbering keeps nothing from being missed.
- "Question only" (or "answer, don't change anything") gets an answer and no code changes.
- For feel/visual feedback, say what looks wrong and what it should look like ("too pink, I want black with a red edge").
- New or changed boss mechanics get a NEW tag in Debug Mode (numpad 5) automatically; the final report lists them.
